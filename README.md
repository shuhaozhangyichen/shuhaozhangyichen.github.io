# 张书豪的数学个人主页 / Shuhao Zhang

中英双语静态学术主页，包含研究方向、9 篇论文、5 次学术报告、教育经历与联系方式。

## 发布到 GitHub Pages

当前连接的 GitHub 用户名为 `shuhaozhangyichen`，目标仓库名为 `shuhaozhangyichen.github.io`。

1. 在该账号下创建上述名称的公开仓库。
2. 将本文件夹中的 `index.html`、`styles.css`、`main.js`、`.nojekyll` 上传到仓库根目录。无需上传 ZIP 本身。
3. 在仓库的 Settings → Pages 中选择 Deploy from a branch，然后选择 main 分支和 / (root)，点击 Save。
4. 等待 GitHub 完成发布。发布成功后的网址为 `https://shuhaozhangyichen.github.io/`。

如果改用其他 GitHub 账号，请相应修改仓库名，以及 index.html 中的 canonical 和 og:url 地址。

## 修改内容

- `index.html`：个人介绍、论文、报告、教育经历；中文与英文界面文字保存在 data-zh 和 data-en 属性中。
- `styles.css`：字体、配色和手机适配。
- `main.js`：语言切换、日期显示和语言偏好记忆。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

论文和报告标题保留原始英文。网页无需数据库、安装依赖或付费服务器。
